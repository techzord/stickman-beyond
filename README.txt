STICKMAN — BEYOND LIMITS (50-LEVEL EDITION)

HOW TO RUN
1. Extract the ZIP.
2. Open the stickman_beyond_limits_updated folder in VS Code.
3. Open index.html in a modern browser. A local server/Live Server is recommended.

CONTROLS — PC
A / D or Arrow Keys: Move
Space / W / Up Arrow: Jump
J or K: Sword attack
S / Down Arrow: Crouch
P / Esc: Pause / Resume
F: Fullscreen
R: Restart current level

CONTROLS — MOBILE
Rotate the phone to landscape for the best view. Use the on-screen left/right,
jump, crouch and attack buttons. Fullscreen is available from the top bar.

PROGRESSION
- 50 levels, with five world themes.
- Levels unlock in order and progress/coins/sword power save in browser localStorage.
- King boss fights are on levels 10, 20, 30, 40 and 50.
- New monster types appear in levels 11, 21, 31 and 41.
- Use the level-select screen to replay any unlocked level.

SOUND / REWARDED POWER
Sound effects and a generated ambient melody use Web Audio, so no external audio files are needed.
The Power Reward menu is still demo-only. Real rewarded ads require an ad provider SDK and a verified reward callback.

NOTES
This is a browser-based HTML/CSS/JavaScript game. Save progress is stored locally in the current browser profile and does not automatically transfer to another device/browser.
